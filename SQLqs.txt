Dbms vs Rdbms 

DBMS (Database Management System)
Stores data in files or simple structures.
Does not enforce relationships between data.
Works for small amounts of data.

RDBMS (Relational Database Management System)
Stores data in tables with rows and columns.
Can link tables using keys (like student → department).
Supports SQL queries to fetch and manipulate data.
Works for large amounts of data.
Examples: MySQL, SQL Server, PostgreSQL, Oracle.

Group By vs Order By
GROUP BY: Groups similar data (e.g., count students by class)
SELECT department, COUNT(*) AS total_employees
FROM employees
GROUP BY department;

ORDER BY: Sorts the data (e.g., by name or age)
SELECT name, salary 
FROM employees
ORDER BY salary DESC;

WHERE vs HAVING (both are filtering clauses)
WHERE: Used to filter before grouping
WHERE Clause is used before GROUP BY Clause. 
WHERE Clause cannot contain AGGREGATE function. 
SELECT * 
FROM employees
WHERE salary > 40000;

HAVING: Used to filter after grouping
HAVING Clause is used after GROUP BY Clause. 
HAVING Clause can contain aggregate function.
SELECT department, COUNT(*) AS total
FROM employees
GROUP BY department
HAVING COUNT(*) > 1;

WHAT ARE ACID PROPERTIES?
->Sure! Here's a simple one-liner explanation for each ACID property:
Atomicity: All steps of a task must happen or none at all.
Consistency: Data must always be valid and follow rules.
Isolation: Tasks run separately, even if done at the same time.
Durability: Once saved, the data won’t be lost — even if system crashes.

A stored procedure is like a saved set of instructions in the database. Instead of writing the same SQL queries again and again, you save them as a procedure and run it whenever you need.
It can take input values.
It can give output values.
It can do many things like select, insert, update, or delete data.
“Stored procedures don’t return values the way functions do. Instead, they can return result sets, output parameters, or an integer status code. If we need to return a value directly, a function is more appropriate.”
