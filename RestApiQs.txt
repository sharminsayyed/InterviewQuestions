

What is a Web API?

A Web API (Application Programming Interface) is a way for applications to communicate with each other over the web using HTTP.

It allows clients (web, mobile, or other applications) to perform operations like Create, Read, Update, Delete (CRUD).

Web APIs usually send data in JSON or XML format.

 WHAT IS REST AND RESTFUL? 
REST stands for Representational State Transfer. It is a set of guidelines 
for desiging apis  where applications can easily communicate 
with each other.


REST Guidelines: 
1. Separation of Client and Server - the implementation of both can be done independently
2. Stateless -  Each request is independent (server doesn’t remember past requests).
3. Uniform interface – Identify of resources by URL 
4. Cacheable - Data can be cached for better performance.
5. Layered system - 

RESTFUL: If a system written by applying REST architectural concepts, it is called 
RESTful services.

How do you secure a Web API?
Common methods:
API Key – Client sends a secret key in headers.
JWT (JSON Web Token) – Stateless token-based authentication.
OAuth2 – Token-based authorization for third-party access.
HTTPS – Encrypts data in transit.
CORS policies – Restrict which domains can call your API.

 WHAT IS TOKEN BASED AUTHENTICATION? 
1)client first sends request to the Authentication server with valid credentials
2) Authentication server /web api then sends Access Token to the client as a response .This token has a expiry time 
3) Client uses this Access token in the header for every next request to access the protected apis 
4)if the Access Token is expired , then the client can request a new Access token by using refresh token 

JWT authentication is a token base authentication where JWT is a token 
format. 
A JWT token is like a digital ID card that proves who you are when you use a website or API.
A string (long text) made of 3 parts (Header, Payload, Signature).
Used to securely pass user identity and claims between client and server.
Header - algorithm - algo used to generate the token
	type - type of token which is jwt 
payload - contains the actual the data like name ,role 
Signature - Used to verify that the issuer is correct and the token is authentic.

API INTEGRATION?
API integration means connecting two or more software systems/applications so they can share data and work together using APIs
FLOW OF API INTEGRATION
1)The .NET application (client) needs data from an API.
2)It uses HttpClient to create a request.
3)The request includes:
	HTTP method (GET, POST, PUT, DELETE)
	Headers
	Authentication tokens
	Request body (if needed)
4)The request is sent over the internet to the API endpoint.
5)The API processes the request and performs the required operations.
6)The API returns a response with:
	HTTP status code (200, 400, etc.)
	Data in JSON or XML format
7)The client parses the JSON/XML into C# objects using JsonSerializer or Newtonsoft.Json.
8)The application uses the parsed data as needed.
